

При переобработке данных вычисляет области данных для возможных корректировок и предоставляет сравнение устаревших и предлагаемых данных. Пользователь, в свою очередь, одобряет или не одобряет внесение изменений.

По функционалу:
 - кнопка "галочка" - подтверждает внесение изменений в конкретно указанном параграфе,предложении или абзаце
 - строка предложения - пользователь самостоятельно вносит комментарий по данному пункту для последующей обработки LLM
 - кнопка редакции - пользователь самостоятельно вносит правки в предложенном варианте предлагаемых данных для последующего внесения
