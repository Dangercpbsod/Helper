
**1. Пользователь добавляет краткую идею проекта.**

- В Obsidian создается новая заметка (или блок) с этой идеей.
- Автоматически запускается n8n-флоу, который:
  - Забирает текст из новой заметки.
  - Отправляет его GPT с промтом на генерацию структуры (основные разделы, содержание).
	  - GPT последовательно обрабатывает заметку:
	1. Извлекает содержание
	2. Проставляет теги и ссылки
	3. Создаёт вложенные задачи
	4. Генерирует дочерние заметки по каждому из пунктов
	5. Повторяет процесс до окончания всех уровней
	6. Обновляет векторную базу (например, с помощью Weaviate или Qdrant).


**2. Пользователь добавляет уточнение/новую заметку.**

- n8n запускает обработку:
  - Извлекает новый текст.
  - GPT анализирует его и векторную базу для получения контекста.
  - Возвращает дополнение без повторений.
  - Создает или дополняет заметку в Obsidian.
